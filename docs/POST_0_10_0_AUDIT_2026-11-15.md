## Confirmed defects and corrections

| Priority | Defect | Correction |
| --- | --- | --- |
| P1 | Delayed auth observations could restore a cleared wallet, overwrite a newer wallet, or publish a replaced SDK session. | Observation sequencing and post-await revision/session checks in `AuthBloc`; three failing-before-fix regressions. |
| P1 | Browser cancellation during the final record read could still return a credential or deletion grant. | Final operation-generation checks before returning sensitive results. |
| P1 | Cancellation during queued IndexedDB replacement/deletion could still mutate the saved credential. | Abort the transaction with the credential operation; verified against real IndexedDB and virtual WebAuthn in isolated Chrome. |
| P1 | Closing the swap screen during revalidation or consent persistence could still submit a swap. | Invalidate pending starts and recheck disposal before dispatch; retain tracking for work already dispatched. |
| P1 | Routed SDK init/cancel/cleanup could reach a replacement engine after asynchronous transport preparation. | Final RPC dispatch guards and engine leases; preserve definite rejection before dispatch and uncertainty afterward. |
| P1 | Two older reviews of the same Solana send could submit twice, including through different managers. | Durable wallet/intent revisions, checked atomically at reservation, supersede older reviews after successful submission; fresh intentional sends remain possible. |
| P2 | A late quote stream update or overlapping aggregate quiet refresh could remove the user's selected fastest alternative. | Retain separately fetched alternatives for their evaluation and preserve explicit selection; discard expired, incompatible-amount and Max additions. The aggregate draft regression failed before the correction in both app branches. |
| P2 | Failed or timed-out consent writes could dispatch anyway or leave the screen stuck; late wallet lookup could attribute consent to another wallet. | Reject false/failed writes, bound consent waits, guard wallet identity and action ownership around asynchronous preparation, allow explicit retry. |
| P2 | `AppStorage.write` reported success when SharedPreferences returned false. | Propagate the actual persistence result; seven regressions cover primitives, structured values and thrown failures. |
| P1 | GitHub build diagnostics could expose credentials echoed in provider response bodies or reason phrases. | Retain status diagnostics without logging untrusted response text; credential-echo regressions. |
| P2 | macOS CI disabled signing despite imported Gleec credentials and blank overrides erased project signing settings. | Use the import result; set unsigned overrides only for unsigned builds; create the action-managed temporary keychain. |
| P2 | Pricing results could be cached/published after a wallet switch or clear. | Bind pricing/cache writes to the SDK session and reject obsolete overview/chart completions. |
| P1 | An in-flight wallet refresh could enqueue new portfolio requests after logout, wallet replacement, disposal, or a newer refresh. | Bind the producer to the full wallet identity, SDK session, active view and load generation; invalidate it on clear/dispose and publish synchronously after the final check. Applied to the shared, Solana, auth and pricing checkouts. |
| P2 | FIFO sales used the first acquisition's price for later lots; floating-point quantities rejected valid fractional liquidations. | Consume each lot at its own cost basis using exact decimal quantities. |
| P2 | Missing historical prices were silently replaced with much later prices, or unavailable assets were omitted from totals. | Report unavailable valuation instead of inventing historical cost basis or presenting partial/zero totals as complete; retain retry backoff. |
| P2 | SDK partial-history and rate-limit paths skipped healthy fallbacks or cached transient outages as missing data. | Fill missing dates from available providers, keep retry order stable and preserve provider cooldown/error semantics. |
| P2 | Future dates could receive today's spot price; midnight rollover could permanently cache an unfinished candle. | Restrict spot values to the current day and bind cache decisions to the request's day boundary. |
| P2 | Blocked/invalid fiat responses became internal errors or indefinite loading. | Validate response shapes, distinguish business rejections from provider unavailability, clear unusable quotes and offer a read-only retry. |
