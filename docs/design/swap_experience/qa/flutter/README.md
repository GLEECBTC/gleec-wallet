# Flutter implementation captures

Captured 2026-11-08 with Flutter 3.41.4 from the real application widgets and
controlled quote/execution fixtures in `swap_ux_capture_test.dart`. These are
rendered components, not a funded transaction or device performance recording.
The normal phone surface is 390 × 844; the keyboard case reserves 336 px for
the keyboard. The large-text review uses 200% text. Desktop is 1280 × 900.

Review covered full-width asset/network identities, stable exact money values,
minimum/destination disclosure, changed-price labeling, readable legal links,
recoverable error copy, evidence-backed receiving/receipt, and reachable
keyboard/large-text actions. The prior desktop value is explicitly labeled
“Previous estimate”; the receipt has one primary action and quiet return links.

The automated accessibility matrix separately checks 375/390/768/1024/1440
widths, both themes, 200% text, control labels, target sizes, and whole words.
Actual screen-reader usability, native haptics, physical-device frame profiling,
healthy-network quote percentiles, funded settlement, and the five-person study
remain human/device release checks.

To regenerate, set `SWAP_CAPTURE_DIR` to an output directory when running
`flutter test test_units/tests/swap/swap_ux_capture_test.dart`. For an existing
asset cache and an app-only check, also use `--no-pub --no-test-assets`.
