KDF web latency probe

This starts a real KDF (WebAssembly) in this tab and it talks to real electrum and EVM RPC servers. Use a throwaway seed. The seed is held in sessionStorage for the duration of the run and cleared at the end; it is never written to disk or sent anywhere except into the local KDF instance.

No Flutter and no Dart are involved. This page imports the same kdflib_bootstrapper.js the app imports and calls mm2_main / mm2_rpc directly — the browser mirror of tool/kdf_latency_probe.py.
