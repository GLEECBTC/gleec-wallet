# Unified Swap QA evidence

The numbered `01`–`18` PNGs referenced by the QA report are workbench captures. Their filenames describe the wallet canvas configured inside the workbench, not the outer image dimensions.

The `19`–`21` PNGs are raw browser-viewport captures. Each is exactly 390 × 844 pixels and contains the wallet canvas without the QA workbench chrome. `manifest.json` records the capture type and dimensions and is verified by `verify-gleec-unified-swap.mjs`.

Eight earlier 1280 × 720 captures were JPEG data with a `.png` suffix. They are retained for provenance with corrected `.jpg` extensions and are not used as final visual evidence.
